# 🎧 Мой домашний Spotify — MusicStream

Привет! Это мой pet-проект — локальный музыкальный стриминг, который я написал за пару вечеров.  
Выглядит как Spotify, но живёт у тебя на компе и позволяет заливать свои треки без всяких облаков и подписок.

---

## 🚀 Быстрый старт

1. Склонируй репозиторий (или просто распакуй архив):
   ```bash
   https://github.com/djjdjdbf9/music_stream_spotifyclone.git
   cd music_stream_spotifyclone
   ```

2. Установи зависимости (нужен Node.js ≥ 14):
   ```bash
   npm install
   ```

3. Запусти сервер:
   ```bash
   npm start
   ```
   Увидишь примерно такое:
   ```
   🎵 Сервер запущен на http://localhost:3000
   📁 Загрузка треков: .../music_stream_spotifyclone/public/uploads
   ```

4. Открывай браузер и переходи на [http://localhost:3000](http://localhost:3000) — всё, музыка у тебя дома.

---

## 🛑 Как выключить сервер

Я всегда делаю просто:

- Возвращаюсь в окно терминала, где запускал `npm start`
- Жму `Ctrl + C`
- Если спросит `Terminate batch job?` — жму `Y` и Enter

Сервер мгновенно падает, порты освобождаются, никаких фоновых процессов не остаётся.

Если вдруг закрыл терминал крестиком — тоже норм, Node.js умрёт вместе с ним.

---

## 🛠 Что умеет

- Загружать mp3/flac/wav через drag-and-drop
- Искать по названию/артисту/альбому
- Плеер с горячими клавишами (пробел — play/pause, стрелки — next/prev)
- Помнит громкость
- Удаление треков (клик правой кнопкой → «Удалить»)
- Тёмная тема, как у нормальных людей

## ❗️Если что-то пошло не так

- **Порт 3000 занят?**  
  Отредактируй `server.js` — поменяй `PORT = 3001` (или любой другой).
- **Не грузит треки?**  
  Проверь, что в папке `public/uploads` появляются файлы после загрузки.
- **Ошибки в консоли?**  
  Пиши в Issues, я не мгновенно, но отвечаю.

Пользуйся на здоровье и не забудь бэкапить свою музыку — SQLite-файл можно просто скопировать куда надо.
